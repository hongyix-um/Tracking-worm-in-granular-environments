# ML-based Worm Segmentation Toolbox

![sample_output](https://github.com/Pyh2002/Worm-Segmentation-ToolBox/assets/72658879/9876febd-ae4c-47bd-afee-9f3f7c387a06)

The main goal for this sub-package is to segment an input video by identifying all the pixels that belong to the worm in each frames. We employ a neural network-based method (resnet34) for the segmentation, creating a binary mask over the worm, which is saved as an output video.
